## §2 — Abstention shootout: strong judge wins, MiniCheck v1 retires

Stand: 40q BEAM abstention row, wd-v2 worlds, `--skip-ingest`, the
v10verifier profile (lenient + abstentionCalibration + topic coverage),
one leg per arm (driver: scratchpad/abst-leg.sh).

| arm | abstained-correct | paired vs baseline |
|---|---|---|
| baseline — LLM verifier, inherit gpt-4o-mini | 0.725 (29/40) | — |
| **arm (a) — verifier on gpt-5-mini** (`verifierModel`) | **0.775 (31/40)** | flips 4:2 FOR (McNemar n.s.) |
| arm (b) — Bespoke-MiniCheck NLI, local (`minicheck`) | 0.55 (22/40) | flips 1:8 AGAINST (p≈0.04) |

Verdicts:
- **Arm (a)** is direction-positive (+5pp) at one cheap extra-model call
  per answer; n=40 cannot confirm it alone — the confirmation gate is a
  bigger-n run (all 400q or the LME abstention block) before default-on
  for any tenant. Build is merged-ready: `RETRIEVAL_VERIFIER_MODEL` /
  profile.verifierModel (4-way wired, overlayable, golden bumped 19→20).
- **Arm (b) v1 RETIRES decisively.** The measured failure is exactly the
  V10 §5 class: fabrications assembled from real facts pass a
  whole-answer consistency check — every atomic claim IS in the
  evidence, the invented CONNECTION is what a claim-level NLI cannot see
  without decomposition; and MiniCheck has no questionAnswered
  dimension at all. Zero degrades in the leg (the local judge ran
  cleanly — the loss is judgment, not plumbing). A decomposed-claims v2
  (answer split + relationship claim as its own hypothesis) is the only
  path worth re-measuring; not built ahead of data.
- Found-and-fixed live along the way: gpt-5*/o* verifier calls 400'd on
  `temperature: 0` and starved a 256 `max_completion_tokens` cap with
  hidden reasoning — 23/40 audits silently degraded to verifier_error
  before the guard (the arm faked 0.45). `runVerifier` now omits
  temperature and widens the cap to 2048 for that model class;
  non-reasoning models keep the byte-identical call.

Stand gotchas (burned, documented):
- `--skip-ingest` + no registry pin → the leg reads whatever
  `RETRIEVAL_DERIVED_VERSION` resolves — unset, that was the 2-fact raw
  world (avgPromptTok 495 vs 5254) and the abstention row scored a
  perfect-looking 40/40 on an empty substrate. Env-pin the world
  (wd-v2) in every skip-ingest driver.
- GitHub closes a dependent stacked PR when its base branch is deleted
  on merge — retarget the child to main BEFORE deleting; base-change
  alone does not fire main-filtered workflows, a close/reopen does.
