# Truth-discovery battery

Measures the nightly truth-discovery pass (#847,
`src/ai/calibration/truth-discovery.ts`). It is mechanical and free: there is
no stand, no model and no judge.

`simulate.ts` builds synthetic workspaces of known truth:

- **independent sources** of fixed accuracy (0.95 down to 0.35);
- **copiers** that repeat the worst source under the same origin;
- **a diligent source** that is never wrong and reports changes of value as
  facts that succeed each other in valid time.

`score.ts` scores each method exactly on the contested slots no user anchored:

| Metric | Truth discovery | Compared with |
|---|---|---|
| pick accuracy | argmax posterior | majority vote (one vote per origin) |
| calibration | ECE of the posteriors (10 bins) | — |
| source accuracy | RMSE vs the real accuracy | the win/loss tally it replaced |
| change control | the diligent source's estimate | the win/loss tally |

The prior strength is picked on tune seeds and reported on eval seeds it never
saw.

```
pnpm eval:truth-discovery
```

Result at the time of #847, 10 eval seeds, ~213 contested slots each:

| Metric | Truth discovery | Comparison |
|---|---|---|
| pick accuracy | 92.7% | majority 84.5% |
| ECE | 0.026 | — |
| source RMSE | 0.037 | win/loss 0.364 |
| diligent source (truly 1.0) | 0.96 | win/loss 0.23 |

**Limitation.** The workspaces are generated by the model the estimator
assumes: one accuracy per source, uniform wrong values, copying visible
through `originKey`. Copying that leaves no shared origin, and correlated
errors, are not represented. The battery shows the estimator does what the
model says. It does not show the model fits a given tenant; the stand
batteries (memfit, STEV) are the check that nothing regresses.
